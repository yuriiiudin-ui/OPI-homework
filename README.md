## 2. Самостійна робота (Розгортання застосунку у хмарі)

### Тема
Розгортання модуля з ЛР 03–04 як REST API на хмарній платформі (PythonAnywhere).

### Мета
Набуття практичних навичок із розгортання веб-застосунку. Оволодіння процесом перетворення програмного модуля на REST API та конфігурування середовища розгортання.

### Реалізований функціонал
Модуль калькулятора знижок `discount.py` було обгорнуто у веб-сервіс за допомогою мікрофреймворку **Flask** (`app.py`). 
Реалізовано два REST API endpoints:
1. **`GET /health`** — для перевірки працездатності застосунку (повертає `{"status": "ok"}`).
2. **`POST /calculate`** — для розрахунку знижки. Приймає JSON із параметрами `customer_type`, `amount` та необов'язковим `qty`.

### Конфігурація та розгортання
- Застосунок розгорнуто на платформі **PythonAnywhere**.
- Публічна адреса: **[https://yuriiiudin.pythonanywhere.com/](https://yuriiiudin.pythonanywhere.com/)**
- Налаштовано конфігураційні файли: `requirements.txt`, `Procfile`.
- Бонусні завдання: створено `Dockerfile` для контейнеризації та `.github/workflows/deploy.yml` для імплементації базового CI/CD пайплайну.

### Локальний запуск та тестування
Для локального запуску необхідно виконати:
```bash
pip install -r requirements.txt
python app.py
```
Для запуску модульних тестів (написаних за допомогою `pytest`):
```bash
pytest test_discount.py
```
