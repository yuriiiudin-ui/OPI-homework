## 4. Результати рефакторингу власного коду

На основі зауважень Ruff, SonarLint та рекомендацій напарника було проведено рефакторинг класу `DiscountCalculator`, розробленого в лабораторній роботі №3.

### Операція 1. Replace Magic Number with Constant

#### Було

```python
if qty > 10:
    return round(base * 0.97, 2)
```

#### Стало

```python
BULK_THRESHOLD = 10
BULK_DISCOUNT_FACTOR = 0.97

if qty > BULK_THRESHOLD:
    return round(base * BULK_DISCOUNT_FACTOR, 2)
```

#### Обґрунтування

Числа `10` та `0.97` є магічними значеннями. Винесення їх у константи покращує читабельність коду та спрощує подальшу підтримку й модифікацію системи.

---

### Операція 2. Simplify Conditional (Guard Clauses)

#### Було

```python
def calculate(self, amount: float) -> float:
    if amount < 0:
        raise ValueError("Amount cannot be negative")
    if amount == 0:
        return 0.0
    return round(amount * self.RATES[self.customer_type], 2)
```

#### Стало

```python
def calculate(self, amount: float) -> float:
    if amount < 0:
        raise ValueError("Amount cannot be negative")

    if amount == 0:
        return 0.0

    discount_rate = self.RATES[self.customer_type]
    return round(amount * discount_rate, 2)
```

#### Обґрунтування

Перевірка помилкових ситуацій здійснюється на початку методу, що дозволяє зробити основний сценарій виконання більш зрозумілим та лінійним.

---

### Операція 3. Extract Variable

#### Було

```python
def apply_discount(self, amount: float) -> float:
    discount = self.calculate(amount)
    return round(amount - discount, 2)
```

#### Стало

```python
def apply_discount(self, amount: float) -> float:
    discount = self.calculate(amount)
    final_price = amount - discount
    return round(final_price, 2)
```

#### Обґрунтування

Виділення змінної `final_price` покращує читабельність коду, робить логіку більш очевидною та спрощує відлагодження.
